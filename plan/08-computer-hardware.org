:PROPERTIES:

** Learn
Every digital circuit can be built from one kind of gate: NAND. Starting
there, you build NOT, AND, OR, XOR, multiplexers, and demultiplexers, each
from the ones before. You describe them in a simple hardware description
language (HDL) and test them against truth tables in the simulator. It's
the same idea as building up a program from small functions, except the
functions are wires.

- [[https://www.nand2tetris.org/software][Nand2Tetris software]]: the hardware simulator (the online IDE works too)
- [[https://www.coursera.org/learn/build-a-computer][Nand2Tetris Part I on Coursera]] (free to audit), week 1 videos

** Checkpoint
How would you make an AND gate from NAND gates alone, and why does it take two?
#+begin_details
#+html: <summary>Check your answer</summary>
NAND is AND followed by NOT. Feed both inputs into one NAND, then invert its
output with a second NAND whose two inputs are tied together, which makes it
a NOT. NOT(NAND(a, b)) = AND(a, b), so it takes two gates.
#+end_details

* TODO Week 34: Combinational logic and the ALU
:PROPERTIES:
:WEEK: 34
:CUSTOM_ID: week-34
:END:
** Learn
Binary addition is built from gates: a half adder adds two bits, a full adder
handles a carry in, and a chain of full adders adds whole numbers. Negative
numbers use two's complement, so the same adder also subtracts. The ALU
(arithmetic logic unit) combines these with a few control bits that choose
the operation. It's the part of the CPU that computes.

- [[https://www.nand2tetris.org/course][Nand2Tetris course]]: project 2 (Boolean arithmetic) and its lecture
- Coursera Nand2Tetris Part I, week 2 videos

** Checkpoint
In 16-bit two's complement, how is −1 represented, and what happens when you
add 1 to it?
#+begin_details
#+html: <summary>Check your answer</summary>
−1 is all ones: 1111 1111 1111 1111. Adding 1 carries through every bit,
leaving all zeros with a carry out of the top bit that's discarded. So the
result is 0, as expected, using the same adder as unsigned addition.
#+end_details

* TODO Week 35: Sequential logic and memory
:PROPERTIES:
:WEEK: 35
:CUSTOM_ID: week-35
:END:
** Learn
Combinational circuits forget: their outputs depend only on current inputs.
Adding a clock and a flip-flop gives a circuit memory: its output now depends
on what happened last cycle. From a data flip-flop you build a 1-bit
register, then 16-bit registers, then RAM in growing sizes, and a program
counter. This is the hardware behind every variable you've ever stored.

- [[https://www.nand2tetris.org/course][Nand2Tetris course]]: project 3 (memory) and its lecture
- Coursera Nand2Tetris Part I, week 3 videos
- Optional: [[https://eater.net/8bit][Ben Eater's 8-bit breadboard computer]], the clock and register videos, to see the same ideas in real chips
- Watch: MIT 6.002 [[https://ocw.mit.edu/courses/6-002-circuits-and-electronics-spring-2007/resources/lecture-14/][lecture 14, State and memory]] (optional: memory seen from the circuit side)

- None (software only)
** Checkpoint
Why can't you build memory from combinational logic alone?
#+begin_details
#+html: <summary>Check your answer</summary>
A combinational circuit's output is a pure function of its current inputs. It
has nowhere to keep a value after the inputs change. Memory needs feedback
plus a clock that decides when to sample: the flip-flop holds its value
between clock edges, regardless of what the inputs do in between.
#+end_details

* TODO Week 36: The CPU and instruction execution
:PROPERTIES:
:WEEK: 36
:CUSTOM_ID: week-36
:END:
** Learn
The Hack CPU combines the ALU, registers, and program counter. Each clock
cycle it fetches an instruction from ROM, decodes its bits into control
signals, computes with the ALU, writes the result to a register or memory,
and picks the next instruction (the next one in order, or a jump). Writing a
few programs in Hack assembly first (project 4) makes the CPU design obvious.
Building the CPU (project 5) completes a working computer.

- [[https://www.nand2tetris.org/course][Nand2Tetris course]]: projects 4 (machine language) and 5 (computer architecture)
- Coursera Nand2Tetris Part I, weeks 4 and 5 videos

** Parts
- None (software only)
** Checkpoint
Trace the instruction =D=D+A= through the CPU: where does it come from, what
changes inside, and where does the result go?
#+begin_details
#+html: <summary>Check your answer</summary>
1. The PC holds the instruction's address, and ROM outputs the 16-bit
   instruction.
2. The top bit marks it as a C-instruction. The computation bits select D + A
   in the ALU, with the D register and the A register as inputs.
3. The destination bits enable a write to D only. On the clock edge, D takes
   the ALU's output.
4. There are no jump bits, so the PC increments to the next instruction.
#+end_details
